# מטלה עשירית - מכולות STL, טאפלים, וקטורים, מחרוזות, סטים, מפות, תכונות טיפוסים וחידות

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים שימוש ב**מכולות STL (Standard Template Library)** בשפת C++. המטלה מתמקדת ביישום מערכת רישום סטודנטים לקורסים תוך שימוש בוקטורים, מפות, סטים, טאפלים, מחרוזות, תכונות טיפוסים וחידות לוגיות.

## מבנה המטלה
במטלה זו תתבקשו לממש מספר קבצי `.cpp` על בסיס קבצי ה-`.hpp` שסופקו. המטלה מדגימה:
- **וקטורים (Vectors)** - רשימות דינמיות של סטודנטים וציונים
- **מפות (Maps)** - מיפוי קורסים לרשימות סטודנטים
- **סטים (Sets)** - ניהול רשימות ייחודיות של רשומים
- **טאפלים (Tuples)** - ייצוג רשומות סטודנט (שם, ת.ז., ציון)
- **מחרוזות (Strings)** - עיבוד שמות וטקסטים
- **תכונות טיפוסים (Type Traits)** - בדיקת טיפוסים בזמן קומפילציה
- **חידות (Riddles)** - פתרון בעיות לוגיות עם מכולות STL

## דרישות והנחיות

- לוודא שהקוד מתקמפל ופועל ללא שגיאות

- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **std::vector** - מערכים דינמיים
2. **std::map** - מיפוי מפתח→ערך
3. **std::set** - קבוצות עם איברים ייחודיים
4. **std::tuple / std::tie / std::get** - טאפלים לריבוי ערכים
5. **std::string** - מחרוזות ופונקציות עיבוד
6. **std::type_traits** - בדיקת תכונות טיפוסים בזמן קומפילציה
7. **Range-based for loops** - מעבר על מכולות
8. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest

## טיפים להשלמת המטלה
- קראו היטב את הוראות המטלה והבינו את הדרישות
- **std::vector** — מערך דינמי עם `push_back`, `size`, `begin/end`
- **std::map** — מיפוי מסודר לפי מפתח, גישה עם `[]` או `find`
- **std::set** — קבוצה מסודרת ללא כפילויות, `insert`, `count`, `find`
- **std::tuple** — מאגד ערכים מטיפוסים שונים, גישה עם `std::get<N>()`
- **std::tie** — מאפשר לפרק טאפל למשתנים נפרדים
- **type_traits** — `std::is_integral`, `std::is_floating_point`, `std::is_same` וכו'
- שימו לב שהקומפילציה משתמשת בדגל `-Wsign-conversion`. פונקציות שמחזירות `int` אך משתמשות ב-`size()` של מכולות (שמחזיר `size_t`) ידרשו המרה מפורשת באמצעות `static_cast<int>(...)` כדי להימנע משגיאות קומפילציה
- בדקו את התוכנית עם מקרי קצה ותנאים שונים
- הקפידו על כתיבת קוד נקי, קריא ומתועד היטב
